ВАЖНО ДЛЯ ДРУГОГО ПОЛЬЗОВАТЕЛЯ:
Просто отправить ZIP на телефон недостаточно удобно, особенно на iPhone.
Лучший способ — разместить содержимое этой папки на любом обычном статическом веб-хостинге.
После этого друг получает одну HTTPS-ссылку и открывает её в Chrome/Safari.
На Android страницу можно добавить на главный экран через меню браузера.
На iPhone: Safari -> Поделиться -> На экран «Домой».

Для локального Android также можно распаковать ZIP и открыть index.html браузером,
но некоторые мобильные браузеры ограничивают локальные аудиофайлы/озвучку.
Поэтому веб-ссылка — рекомендуемый вариант.
